# BookUp IQ presentation

A short slide deck that introduces BookUp IQ, the clinic operating layer that turns ads and WhatsApp messages into booked, attended and paid consultations. It covers the problem, the BookUp loop, a walkthrough of the product with screenshots and recordings, the staff roles, the platform it is built on, the MVP scope and the roadmap.

Open `index.html` in a browser, or view the published version on GitHub Pages. Use the arrow keys, space, the on-screen buttons, a click or a swipe to move between slides. Add `#n` to the URL to open slide n.

The screenshots and recordings in `assets/` come from the BookUp IQ prototype and contain only fictional demo data.
